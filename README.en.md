## Differences from the upstream project

This repository is an unofficial enhanced fork of [RanAxro/nikki_albums](https://github.com/RanAxro/nikki_albums). The original project and its core functionality were created by RanAxro. This fork keeps the existing features and overall structure while adding the following changes:

- **Visual refinements**: Updated colors, typography hierarchy, corner radii, menus, tooltips, scrollbars, and other details according to `DESIGN-airbnb.md`, and removed the visually inconsistent black outer window border. Existing functionality and the main layout remain unchanged.
- **Select photos by date**: A checkbox is displayed before each date heading, allowing all photos from that date to be selected or deselected at once. Partially selected dates use an indeterminate state, and multiple dates can be selected before using the existing delete, move, export, or other batch actions.
- **Photo action tooltips**: Hovering over the action icons on a photo now identifies them as “Tag” or “Add to Parameter Manager.” The Parameter Manager action saves camera parameters or share codes parsed from the photo.
- **New “Export HQ & Clean Up” action**: Selected High Quality photos can be exported to a user-selected local folder. After a file is copied and verified successfully, its source High Quality file is moved to the application's recycle bin.
- **Selectable cleanup of matching versions**: A confirmation dialog lets the user choose whether to also clean up matching Low Quality, Screenshot, Magazine Photos, Clock-In Photo, and Collage Photo versions. Low Quality and Screenshot are selected by default. Selected files are moved to the application's recycle bin rather than permanently deleted.
- **Safer export behavior**: When a file with the same name already exists in the destination, a non-conflicting filename is generated automatically. If a photo fails to export or verify, neither its source file nor its matching versions are cleaned up.
- **Restricted IndexNow workflow**: The workflow that submits updates to the original author's website, `nikki.ranaxro.com`, is allowed to run only in the upstream `RanAxro/nikki_albums` repository, preventing this fork from notifying the original website accidentally.

> “Export HQ & Clean Up” moves photo files. When using it for the first time, test with a small selection and verify the exported results.

<h2>🌟 Your Reliable Game Album Management Tool</h2>

Nikki Albums is a desktop utility for managing all your in-game albums and share codes from *Infinity Nikki*.

🚀 **Current Version**: 3.010
- **GitHub Download**: [Click here](https://github.com/RanAxro/nikki_albums)
- **Official Website Download**: [Click here](https://nikki.ranaxro.com/en)

***

# 🎯 Core Features
- **Automatic Game Detection**: No manual configuration required. The program automatically locates your game directory and quickly loads album resources.
- **Multi-Account Isolated Management**: Organize albums for multiple game accounts independently without data interference, keeping your photo library neatly sorted.
- **Full Album Coverage**: Supports management for all 19 regular albums plus 3 in-game resource albums.
- **Batch Processing Tools**: Perform bulk backup, restoration, transfer, deletion, copying and moving for album photos to drastically boost your management efficiency.
- **Duplicate Photo Auto-Cleanup**: Automatically filter redundant duplicate images generated by the game during photo moving or deletion, keeping your album tidy.
- **Basic Image Editing**: Built-in tools for simple image cropping and color grading.
- **Local Network File Transfer**: Transfer images seamlessly across devices within the same local area network.
- **Convert Videos to Live Photos / GIFs**: Transcode videos from the Motion Album or external video files into Android/iOS Live Photos or animated GIF files.
- **Album Metadata Decoding**: View shooting coordinates and camera parameters to easily recreate your perfect in-game shots.
- **Parameter Manager**: Store, parse and manage camera configurations, outfit codes and home space codes.

# Changelog
## v3.010
### New Features
1. Added search function in Parameter Manager; searchable targets include names, tags, clothing names, suit names, lighting presets and filters.
2. Auto strip plain text and irrelevant symbols when pasting or manually inputting share codes.
3. New feature to generate QR codes for outfit sharing codes.
4. Outfit code history records are sorted in reverse chronological order (newest first).
5. Support custom storage path for parameter data files.

### Performance & Optimizations

### Bug Fixes
